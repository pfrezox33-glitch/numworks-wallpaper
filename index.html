Thèmes NumWorks

Application pour N0110 : six palettes intégrées (Clair, Sombre, Océan, Rose, Nature, Lavande) et aperçu facultatif d'une image importée.

1. Prépare une image (facultatif)


Importe une photo pour générer son fichier de données.

2. Application NumWorks

Haut/Bas pour choisir un thème ; OK ou EXE pour afficher l’image jointe.

3. Transfert USB

  1. Télécharge le fichier .nwa et le .bin si tu utilises une photo.
  2. Branche la calculatrice et ouvre l’installateur officiel.
  3. Connecte la N0110, sélectionne le .nwa puis le .bin comme données externes si l'installateur le demande.
  4. Installe, puis ouvre « Themes » depuis le menu des applications.

Limite importante : Epsilon d’origine ne permet pas à une application externe de changer le thème système ou le fond permanent du menu d’accueil. Les palettes changent l'interface de cette application. L’installation n'efface pas les applications existantes et ne flashe pas le firmware.
