2Prépare le transfert

Le site transforme ton image en programme Python compatible avec l’application Python d’Epsilon. Le programme dessine l’image sur l’écran lorsque tu l’exécutes.

3Envoie-le sur la calculatrice

1. Clique sur « Créer le programme Python » pour télécharger le fichier .py.
2. Ouvre ton espace NumWorks et connecte-toi.
3. Dans « Mes scripts », crée/importes le script puis clique sur « Envoyer vers ma calculatrice » avec le câble USB branché.
4. Sur la calculatrice, ouvre Python et exécute le script.

Sans Omega : le transfert passe par le service officiel NumWorks. L’image s’affiche dans Python ; elle ne remplace pas le fond de l’écran d’accueil.

Le site génère le fichier Python, mais ne peut pas envoyer directement le script à ton compte NumWorks. Le transfert USB final se fait depuis « Mes scripts ».

Projet indépendant, non affilié à NumWorks. WebDFU et format OBM basés sur Omega-External (AGPL-3.0). L'image est convertie localement.
