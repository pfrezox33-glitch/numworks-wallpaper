2Prépare ton application

Cette application externe Epsilon affiche ton image en plein écran sur la NumWorks N0110, sans Omega. Elle se lance depuis le menu des applications ; elle ne remplace pas le fond du menu d’accueil.

3Installe ton image

1. Télécharge l’application .nwa ci-dessus.
2. Clique sur « Télécharger les pixels (.bin) » à gauche pour créer le fichier de ton image.
3. Ouvre l’installateur NumWorks, branche la calculatrice et clique sur Connecter.
4. Sélectionne le fichier wallpaper.nwa. Quand l’installateur demande un fichier de données externe, sélectionne le .bin téléchargé.
5. Clique sur Installer et attends la fin du transfert. Sur la calculatrice, ouvre « Wallpaper » dans le menu des applications.

Prêt : choisis une photo, télécharge le fichier .bin et installe-le avec l’application .nwa. Aucun firmware Omega n’est utilisé.

Nécessite une NumWorks N0110 avec une version d’Epsilon prenant en charge les applications externes (Epsilon 16 ou ultérieur). Après installation, l’image s’affiche dans l’application Wallpaper, pas comme fond permanent du menu d’accueil.

Projet indépendant, non affilié à NumWorks. L’image est convertie localement ; aucun firmware alternatif ni Omega n’est nécessaire pour créer le programme Python.
